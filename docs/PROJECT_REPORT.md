# Software Engineering Project Report: MailGuard
**AI-Powered Gmail Priority Assistant for Final Year Students**

---

## Abstract
Final-year university students face an overwhelming volume of emails daily, spanning campus placement drives, internship interviews, academic thesis deadlines, and general announcements. Misplacing a critical interview invite or missing a registration deadline can severely impact a student's career trajectory. **MailGuard** addresses this issue by combining Google Gemini 1.5 Flash AI with Gmail REST APIs, offering automated priority classification, strict deadline extraction, job application lifecycle tracking, and push notifications via Flutter mobile client.

---

## 1. Project Overview & Problem Statement
Students receive hundreds of unorganized emails each week. Standard email clients categorize emails into broad buckets (Primary, Promotions, Social) which fail to address student-specific needs such as distinguishing between a placement drive update vs. a general university newsletter.

**Key Objectives:**
1. **Intelligent Categorization**: Automatically classify emails into *Placement*, *Academic*, *Personal*, *Promotions*, and *Others*.
2. **Priority Scoring**: Assign *High*, *Medium*, or *Low* priority with explicit AI reasoning.
3. **Deadline Extraction**: Automatically extract due dates and populate a dedicated deadline tracker.
4. **Application Tracking**: Maintain a company-grouped timeline of job application stages (*Applied*, *Interview*, *Offer*, *Rejected*).
5. **Security & Data Privacy**: Bank-grade 256-bit AES encryption for stored refresh tokens and zero non-consensual data retention.

---

## 2. Architecture & Design Specifications
MailGuard implements a layered Model-View-Controller (MVC) architecture on the backend coupled with a clean, feature-first Riverpod state management pattern on the Flutter mobile client.

### System Components:
- **Flutter Mobile Client**: Material 3 UI complying with "The Calm Assistant" design language (Primary: Deep Blue `#00458f`, Accent: Amber `#fdaf00`).
- **Node.js / Express Backend**: Secure REST API serving mobile clients, enforcing JWT authentication, rate limiting, and input sanitization.
- **MongoDB Atlas**: Document database featuring compound unique indexes, text search indexes, and automatic TTL index for security logs.
- **Google Gemini 1.5 Flash**: Natural language processing model invoked via system prompt engineering enforcing strict JSON outputs.
- **Firebase Cloud Messaging**: High-priority push notifications for time-sensitive emails.

---

## 3. Database Schema Design

### Collections Summary:
1. **Users**: Stores Google profiles, encrypted refresh tokens, FCM tokens, and notification preferences.
2. **Emails**: Contains message bodies, AI classifications, priority scores, confidence metrics, and manual override flags.
3. **Deadlines**: Stores auto-extracted and manually added deadlines with overdue auto-detection.
4. **Applications**: Tracks job application status histories grouped by company name.
5. **Notifications**: Tracks FCM push delivery status and unread counters.
6. **AuditLogs**: Maintains operational security logs with 1-year TTL auto-deletion.

## 4. Verification & Quality Assurance
The system has been thoroughly validated using automated unit, integration, and security testing:
- **Unit Tests**: Encryption/decryption algorithms, JWT token rotation, date utilities, Gmail mime parsing, and fallback keyword classifier.
- **Integration Tests**: In-memory MongoDB testing with Supertest covering full HTTP lifecycle, pagination, and database model constraints.
- **Security Tests**: RBAC enforcement, NoSQL injection prevention, authentication bypass prevention, and cross-user data isolation.
